# Regeln für dieses Projekt

## Sprache
- Antworte immer auf Deutsch.
- Verwende einfache Sprache: kurze Sätze, wenig Fachwörter. Wenn ein Fachwort nötig ist, erkläre es kurz.

## Technik
- Verwende nur HTML, CSS und JavaScript.
- Binde keine externen Bibliotheken oder Frameworks ein (kein CDN, kein npm, keine Fremd-Skripte oder fremden Stylesheets).

## Sicherheit
- Schreibe niemals Passwörter, API-Schlüssel, Tokens oder andere Zugangsdaten in Dateien dieses Projekts.
